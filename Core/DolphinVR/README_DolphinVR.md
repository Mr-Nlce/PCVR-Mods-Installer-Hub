# Dolphin VR + ReduX

A VR-capable fork of the **Dolphin** GameCube / Wii emulator, letting you play Nintendo classics in stereoscopic 3D and VR. The Hub points at the **ReduX / DolphinXR** line maintained by **iChris4** (OpenXR), alongside the long-running Dolphin VR project.

> This is an **external** tool: the Hub links you to the Dolphin VR downloads page. The builds and community live on the project's Discord.

## What you get
- Play **3D GameCube/Wii games in VR** with accurate life-size scale, full FOV, a 3D HUD, independent aiming, and free look
- Play **2D games on a life-size virtual screen** at the correct angle (sometimes even in 3D)
- DolphinXR (iChris4) adds modern **OpenXR** support, a VR settings panel, a VR input tester for Wii Remote config, a Shader Hunter with per-shader overrides (Skip, Fullscreen, Virtual Screen, Headlock, Units-per-Meter, Flag), and initial AR-mode support
- All the usual Dolphin emulator strengths: HD internal resolution, controller support, enhancements

## Requirements
- Windows 10 (1903+) for the DolphinXR/OpenXR builds
- A modern CPU (dual-core 3 GHz+ with SSE2) and a Direct3D 11.1 / OpenGL 4.4-capable GPU recommended
- An OpenXR-compatible VR headset
- Your own legally-obtained game backups (the emulator ships no games)

## How to install (external)
1. Open the info page (dolphinvr.wordpress.com downloads) or the project's Discord to grab the current ReduX / DolphinXR build.
2. Configure your VR runtime (OpenXR) and controllers in the VR settings panel.
3. Load a game; use the VR options to set scale, HUD, and aiming.

> Emulator VR is inherently experimental - expect per-game tweaking (and some games run better than others).
