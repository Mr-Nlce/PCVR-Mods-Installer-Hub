# Kerbal Space Program VR

**Mod:** KerbalVR (latest release auto-fetched)
**Author:** JonnyOThan / FirstPersonKSP
**Full guides:** https://github.com/FirstPersonKSP/Kerbal-VR/wiki

## Before you start

- KSP **1.12.3 or later** on a clean install (modded saves clash)
- **SteamVR 2.8 stable** - NOT the Beta, NOT Theater Mode
- A SteamVR-compatible headset (link cable, Virtual Desktop, ALVR)

## Launching the game

1. Connect your headset
2. Launch **SteamVR first**
3. Launch KSP normally from Steam
4. Load into a flight, then press **Alt+V** to enter VR

Nothing shows in the headset until you press Alt+V in flight. The
main menu and VAB are not VR - only flight (IVA + EVA) is.

## Reset headset view

Press **C** to recenter, or the SteamVR system button.

## Controls

### IVA (in the cockpit)

- **Buttons & switches:** extend index finger, push the button or
  flip the switch with the fingertip
- **Covered switches:** open the cover with your finger first
- **Twist knobs:** pinch (Trigger + B on Quest 2), rotate hand
- **Levers (gear, flaps):** pinch and move up/down
- **Throttle:** grip the lever on the left of the seat, push forward
- **Flightstick:** grip the stick on the right; twist + tilt for
  roll/pitch/yaw. Click the thumbstick while holding it to swap
  rocket-mode and plane-mode mapping
- **Tiny buttons giving you trouble:** hold PinchIndex + PinchThumb
  away from any object to summon a laser pointer
- **EVA from cockpit:** grip the hatch lever, turn it
- **Switch kerbal / take empty seat:** put your hand on the torso
  area, press SeatInteraction (lower face button)

### EVA

| Action | Button |
|---|---|
| Move | [[Left Stick]] |
| Turn | [[Right Stick]] |
| Jump | Right lower face button |
| Sprint | Click [[Left Stick]] |
| Toggle RCS (in space) | Left lower face button |
| Grab ladder / wall | Grip button |
| Up/down on ladder | [[Left Stick]] or triggers |
| Board pod | Grab hatch lever with grip, move it |

**Part Action Window:** hold the RightClick button ([[B]]/[[Y]] on Quest 2)
to open it; a laser appears on the other hand for selecting parts.
Tap the menu with your fingertip.

**Jetpack:** left stick moves, right stick yaw/pitch, triggers go
up/down. Click left stick = precision mode.

## Adding more mods later

The installer drops `ckan.exe` into your KSP folder. Run it from
there to add DE_IVAExtension, Reviva, MAS, or anything else.

## Troubleshooting

- **KSP window stays white / loading bar spins forever** -> you are
  on the SteamVR Beta or Theater Mode. Switch SteamVR to stable.
- **No VR headsets on kerbals at the main menu** -> the install is
  missing something. Run Full Install again on a clean KSP.
- **Play without VR temporarily** -> launch KSP with `-vrmode None`
- **Reviva picks the wrong IVA** -> you must select the IVA per-part
  in-game, otherwise you get the stock default

Full controls (FreeIva, command seats, parachutes, hand tracking)
are on the wiki: https://github.com/FirstPersonKSP/Kerbal-VR/wiki/User-Guide
