# Call of Duty: Modern Warfare 2 Campaign Remastered VR

## About the Game

Modern Warfare 2 Campaign Remastered revisits Task Force 141's single-player missions with updated visuals. Aeka0's Overlord beta adds stereoscopic VR, tracked hands, physical weapon handling and a launcher for VR settings. This is a campaign mod for the Battle.net PC release; multiplayer is not part of Campaign Remastered.

## What you need

- A legally owned, fully installed Battle.net copy of **Call of Duty: Modern Warfare 2 Campaign Remastered**, with `MW2CR.exe`, its game codec and the `Data\data` game storage. The usual location is `C:\Program Files (x86)\Call of Duty Modern Warfare 2 Campaign Remastered`. If yours is elsewhere, select its folder in the installer.
- A connected PC VR headset, tracked controllers and a working OpenXR runtime. The publisher recommends OpenXR; OpenVR/SteamVR is a manual backup. With Steam Link, connect SteamVR before launching. Virtual Desktop can use VDXR or SteamVR according to your selected runtime.
- The official Overlord release archive. The Hub resolves the current GitHub beta, installs the publisher's launcher, loader, input bindings and `h2-mod` resources beside `MW2CR.exe`, and records the installed version. It does not download the game.

Unsigned VR files can trigger antivirus warnings. A missing file may also result from a copy, path or permissions problem; check the installer log and security history before assigning a cause.

## Install, update and start

1. Choose [[Install]] or [[Update]] on this tile. Read each screen and press Enter before locating the game, downloading the current beta, and writing files. Keep the game and Overlord closed during installation.
2. If the game is outside the standard Battle.net folder, select the folder containing `MW2CR.exe`. The mod files are placed in that same folder. Existing same-name files are backed up; saves and unrelated files are retained.
3. **Use [[Start in VR]] in the Hub.** It opens `overlord.exe` from the game folder. Complete the publisher launcher's first-use setup, connect the headset and both controllers, then choose **Singleplayer**. On the launcher page **VR Settings > Basics**, OpenXR is recommended; OpenVR is the backup.

The publisher lists this as a beta. Thermal-view black screens, reversed Predator-drone controls, crashes in some combat sequences, and device-specific input issues are under investigation. For AMD GPUs that fall back to flat view, the publisher suggests disabling anti-aliasing or using FXAA. Launcher depth-of-field and motion-blur switches also change the normal game's graphics settings.

## Controls

Beta 7 adds **Hold/Toggle grip**, **Keep support grip attached**, default weapon hand and equipment positioning under Personalization. **World size** is in calibration and applies on the next launch. To report a startup crash or freeze, use the launcher's diagnostics or [[Ctrl]] + [[Shift]] + [[F8]] while the issue is present; include its crash ZIP from `minidumps` when available. These diagnostic improvements do not mean all startup crashes are fixed.

| Button | Action |
| --- | --- |
| [[Left Stick]] | Move. |
| [[Right Stick]] | Turn; choose smooth or snap turning in VR settings. |
| [[Either Grip]] | Hold a weapon at its grip point; release near a compatible body holster to stow it. |
| [[Either Trigger]] | Fire with the weapon hand, or manipulate ammunition and weapon parts with a free hand. |
| [[Grenade-hand Trigger]] | With the pin ring at your mouth, hold and pull the grenade away to remove its pin. Release, then press again to start cooking a frag grenade. |

The exact reload action varies by weapon. The publisher launcher's Help page explains magazines, slides, charging handles and controller alignment. Bindings may differ by controller and runtime.
