# Gears of War: E-Day VR

## About the Game

Experience Emergence Day as Marcus Fenix and Dom Santiago confront the first Locust invasion. Fight through the collapse of Sera in a brutal story about brotherhood and survival.

## Install and Start

1. Use Start in VR in the Hub. This opens the publisher's GoWEDay_VR.exe launcher.
2. Start SteamVR and make it the active OpenXR runtime. In the launcher, select the game folder or the actual GoWEDay-Steam.exe, then press Start. Windowed is optional.
3. At the title screen, hold [[X]] on the left controller to enter offline campaign mode. Use VR SETTINGS in the pause menu for turning, primary hand and button mapping.

Keep the complete launcher folder together. It starts the game in the publisher's offline mode, loads its virtual gamepad and injects its bundled patched UEVR. Do not replace it with a generic UEVR profile or the protected multiplayer launcher.

The publisher launcher remembers your path in path.txt, creates steam_appid.txt next to the Steam game EXE and asks before copying its profile into AppData/UnrealVRMod. Setup leaves existing roaming profiles alone. Steam campaign, currently tested only as Marcus; left-handed mode is beta. Xbox is untested and is not redirected to Steam.

## Controls

Default right-handed mapping from the publisher scripts. VR SETTINGS can remap the six face/stick actions; left-handed mode mirrors the hands.

| Button | Action |
| --- | --- |
| [[X]] (hold at title) | Enter offline campaign mode. |
| [[Left Stick]] | Move. |
| [[Right Stick]] | Turn (smooth or snap in VR SETTINGS). |
| [[Right Trigger]] | Fire in default right-handed mode. |
| [[Left Trigger]] | Sprint with the support hand. |
| [[Left X]] | Interact. |
| [[Left Y]] | Jump / mantle / climb. |
| [[Right A]] | Drop magazine. |
| [[Right B]] | Pause menu, including VR SETTINGS. |
| [[Left Stick Click]] | Dash. |
| [[Right Stick Click]] | Toggle laser. |
| [[Grip]] | Grab weapons / use the physical interaction appropriate to the hand and weapon. |
| [[Insert]] | Open the advanced UEVR menu. |

## Updates and Removal

Use the Hub installer for the latest official Windows VR package. A failed copy or incomplete package does not mark the update complete. Setup backs up replaced files; Uninstall now removes only unchanged Hub-owned files and restores originals. Changed user settings, saves, textures, disc images and unrelated files are kept.
