# I Can Gun VR

A standalone tactical first-person shooter by **Patrick Koenig**, distributed free on itch.io. You operate your weapon in full manual detail while scavenging procedurally generated levels for documents, guarded by merciless machines. Openly inspired by Wolfire's *Receiver*.

## What you get
- Fully manual weapon handling, simulated down to the round
- Procedurally generated levels to scavenge each run
- Hostile machines (turrets / drones) with no mercy setting
- Playable with Mouse + Keyboard and/or in VR (HTC Vive, Oculus Rift)

## How to install
1. The installer opens the itch.io page in your browser.
2. Download **`i-can-gun-win.zip`** (~597 MB) from the Download section.
3. Back in the installer window, **drag-and-drop the ZIP** (or paste its full path) and press Enter.
4. The installer extracts it to `C:\Games\I Can Gun VR` and creates a desktop shortcut.

## How to launch
Start **SteamVR** (or your OpenXR runtime) first, then either:
- Use the Hub's **Start in VR** button (runs `ICG.exe`), or
- Use the desktop shortcut **I Can Gun VR**.

## Controls
The weapon is operated manually and in full detail, so the game ships its own interactive, on-demand help:
- `[F1]` - toggle the in-game **interactive help** overlay (shows every current weapon-handling input)
- `[Startup dialog]` - pick a lower graphics quality here if you hit performance issues

In VR the same manual operations are mapped to your **motion controllers**; the exact per-action bindings are shown live by the in-game `[F1]` help for your headset, so check it on your first run.
