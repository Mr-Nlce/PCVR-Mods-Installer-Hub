# Star Wars: X-Wing VR

**XWVM** (the X-Wing VR Mod) by the **XWVM Team** - a full VR conversion of the classic **Star Wars: X-Wing Special Edition**, with an in-cockpit VR camera, modern resolutions, and updated controls. It has been roughly a decade in the making.

> This is an **external** mod: the Hub links you to the XWVM page on ModDB. The mod runs as its own launcher (`xwvm.exe`) next to your existing game install.

## Important: which version
XWVM targets **Star Wars: X-Wing Special Edition** (the 1998 Windows release). The installer auto-detects a **Steam** or **GOG** copy of the game, so own it on one of those before you start.

## Controls (read this)
X-Wing is a **gamepad / joystick** game - a flight sim at heart. In VR you fly with a **controller (gamepad or HOTAS), not motion controllers**. Tracked VR controllers only work in the **menus**; the actual flying is stick-and-button. Make sure a gamepad or joystick is connected.

## Setup (XWVM Core - the main mod)
1. On the Downloads page, get **XWVM Core** - this is the main mod.
2. Run the downloaded installer `.exe`. It installs the mod into a folder of your choice and creates **`xwvm.exe`** there.
3. Launch **`xwvm.exe`**. It normally **auto-detects your Steam or GOG X-Wing install** - just confirm the detected path.
4. Go to **Settings -> Camera** and switch it from **Normal** to **Virtual Reality**.

That is the whole setup - launch and fly.

## Optional extras (most pilots will want these)
Both are on the same ModDB Downloads page and are optional.

**XWVM HD Asset Pack** - higher-resolution art and models. It is a zip with its own `.exe` installer; run it **after** the Core mod. The HD assets appear to be **enabled by default** once installed.

**XWVM In-Flight Mission Dialogue** - adds spoken mission dialogue during flight. Inside its zip is a **`GlobalSidecars`** folder; copy that folder into:

`%AppData%\XWVM`  (i.e. `C:\Users\<YourName>\AppData\Roaming\XWVM`)
