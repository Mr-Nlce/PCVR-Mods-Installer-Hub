# Call of Duty: Black Ops VR

## About the Game
Enter the Cold War as Alex Mason, fight through covert operations and uncover the meaning of the numbers. Survive the Zombies maps with physical weapons, manual reloads, tracked hands and roomscale movement.

## Requirements
The fully updated Steam single-player version of Call of Duty: Black Ops (2010) is required, including Steam DVD copies. Xbox / Microsoft Store and multiplayer-only installations are not supported by the publisher. Choose Campaign or Zombies; do not use this mod for competitive multiplayer.

Connect a PC VR headset and select its active OpenXR runtime. SteamVR needs version 2.17 or later for this 32-bit game. Meta Quest Link, Virtual Desktop and Windows Mixed Reality are also listed by the publisher.

## Install and start
1. Close Black Ops and its BO1VR launcher. Choose Install in the Hub; the complete current publisher ZIP is installed beside BlackOps.exe. Existing same-name files are backed up, while saves and edited settings are kept.
2. Use Start in VR in the Hub. On first launch, wait a few seconds while BO1VR prepares its files. Then choose Launch game in the publisher launcher.
3. Alternative: use the Call of Duty Black Ops VR desktop shortcut, then Launch game. Select Campaign or Zombies in the game menu.

Flat / VR parks the graphics proxy for ordinary flat play through Steam. Close both game and launcher before switching. A Hub update preserves the parked mode. Opening BO1VR again prepares the mod for VR; ordinary Steam Play is not the recommended VR start.

## Controls
| Button | Action |
|---|---|
| [[Left Stick]] | Move |
| [[Right Stick]] | Turn; adjust smooth or snap turning in VR Settings |
| [[Grip]] at hip or shoulder | Draw a gun; the other hand supports a two-handed weapon |
| [[Trigger]] on the gun hand | Fire |
| [[Trigger]] on the free hand | Handle magazines, bolts and slides for physical reloads |
| [[A]] | Interact; campaign prompts can also use this for contextual melee |
| [[X]] | Pause; select VR Settings in the pause menu |
| [[X]] held for a second | Recenter |
| [[Menu]] held, or [[F6]] | Open VR Settings |
| [[Left Trigger]] + [[Right Trigger]] held in a T-pose | Calibrate arms in Body & loadout |
| [[Trigger]] or [[Grip]] near an interactive object | Physical use: doors, wall buys and perk machines |

The BO1VR launcher's Help page covers each controller layout, reloading, pouches and calibration. Calibrate standing height under Comfort; use Body & loadout to position holsters and pouches. Roomscale collision, gunstock support and Zombies hit count are adjustable.

## Help
If the headset stays black or VR closes, start again: Beta 1.2 tries the other renderer automatically after a failed VR start. If needed, try SteamVR with Steam Link and share the BO1VR log. For missing Index controllers, verify the default SteamVR binding. For damaged mod files, click the beta version at the bottom right of the publisher launcher and choose Repair.

Missing files alone do not prove antivirus removal. Check the setup log, selected game folder and Windows protection history for a matching event. Retry can reopen the official release page and accept a manually downloaded publisher ZIP.

## Technical details
Start in VR opens BO1VR.exe beside BlackOps.exe, with the game folder as its working directory. BO1VR's Launch game uses Steam app 42700. The VR runtime includes d3d9.dll, openxr_loader.dll and the BO1VR folder containing its data, manifest, settings template, DXVK and licences. The publisher creates its own settings and install backup when first initialized. Diagnostic logs are in %LOCALAPPDATA%\BO1VR\logs. Retain the publisher's backup until its Uninstall has restored the game.
