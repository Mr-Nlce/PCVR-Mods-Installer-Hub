# Shadow Warrior VR

RazeXR brings the classic Shadow Warrior to true stereo PC VR with roomscale motion controls and voxel weapons held at the controller. The shared PCVR port supplies 91 hand-weapon models across its seven supported Build-engine games.

## About the Game

Lo Wang's original Build-engine campaign runs from your owned data in a clean portable VR installation.

## Supported releases

- Steam: Shadow Warrior Classic Redux or Shadow Warrior Classic Original.
- GOG: Classic Redux or Classic Complete.
- Another original copy containing `SW.GRP`.

Wanton Destruction and Twin Dragon are recognized from the supported Redux add-on data and receive their own launchers.

## What the VR port adds

The Windows port combines Raze with Team Beef's RazeXR tracking and input layer, then adds true OpenXR stereo, a desktop mirror, smooth turning, direct launchers and controller-held voxel weapons. Shadow Warrior's original pickup voxels supply part of its hand-weapon set, while a compatible scenery pack can be fetched from its author's source. Fists and the sword remain flat because no matching voxel model exists.

[[Left Stick Click]] is important here: selecting the weapon already in hand reaches the alternate quad shotgun and nuke. GOG editions include the original CD-audio tracks and the setup copies them. Virtual Desktop with VDXR on Quest 3 is the author's tested VR route.

## Install and play

The Hub installs the shared engine at `C:\Games\RazeXR PCVR`, copies compatible data and creates a direct Shadow Warrior launcher. No commercial data is bundled. Start your OpenXR runtime first, then use **Start in VR**.

The current publisher build can show yellow `deprecated checktype` script warnings while starting. They come from its bundled Raze game scripts and are non-fatal when the game continues to load.

## Current RazeXR v1.1 update

The weapon wheel, gun-aligned crosshair, steadier turning and correctly shaped menus are in the current shared PCVR engine. Hold the gun-hand stick click to open the wheel, reach toward a weapon and release; time slows while choosing. Crouch is [[X]]. The wheel can be disabled in VR Options to restore stick-click crouch. Version 1.1 also keeps drawing to the headset after desktop focus changes and can start flat when no headset is connected. Valve Index and Pimax changes were reported without publisher hardware testing.

## Controls

| Button | Action |
|---|---|
| [[Dominant Trigger]] | Fire |
| [[Off-hand Trigger]] | Alternate fire |
| [[A]] | Jump |
| [[B]] | Open / use |
| [[X]] | Crouch |
| [[Gun-hand Stick Click Hold]] | Open weapon wheel; reach toward a weapon and release to select |
| [[Y]] | Toggle map |
| [[Left Stick Click]] | Re-select / alternate weapon; required for quad shotgun and nuke |
| [[Right Stick Up / Down]] | Next / previous weapon |
| [[Dominant Thumbrest]] | Quick kick |

Hold the gun-hand [[Grip]] for the inventory layer: use [[Dominant Stick Down / Up]] to select the next or previous item, [[Grip]] + [[A]] to use it, [[Grip]] + off-hand [[A]] / [[B]] to fly down / up, and [[Grip]] + [[Off-hand Stick Click]] to land.

## Uninstall

Use **Uninstall now**. The portable Shadow Warrior copy and launchers move into a dated recovery folder; the shared engine, other games and your original installation remain.
