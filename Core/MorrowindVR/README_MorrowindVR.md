# Morrowind VR

**OpenMW VR** by **Mads Buvik Sandvei (madsbuvi)** - plays **The Elder Scrolls III: Morrowind** in VR through the open-source OpenMW engine. Stand on the ashlands of Vvardenfell with full motion controls.

> This is an **external** tool: the Hub links you to the OpenMW VR releases. It's a complete engine re-implementation, not a mod over `Morrowind.exe`.

## What you get
- Full 6DOF VR with motion-controller support
- Stereoscopic rendering, with optional **multiview** single-pass rendering (Nvidia GPUs) for better performance
- All of OpenMW's engine benefits over the 2002 original: native Windows/macOS/Linux support, better physics and AI, distant terrain, improved save management, post-processing (bloom, HDR, AO, etc.), and broad mod support

## Requirements
- A **legal copy of Morrowind** (and its expansions) - OpenMW needs the original game's data files
- A PCVR-ready setup with an OpenXR/OpenVR headset
- An Nvidia GPU is recommended if you want the faster multiview stereo path (it's the only one supported for that mode so far)

## How to install (external)
1. Open the info page (madsbuvi's OpenMW VR releases) and download the VR build.
2. Run OpenMW's installation wizard and point it at your Morrowind data files.
3. Launch the VR build.

Full manual: https://openmw-vr.readthedocs.io/en/latest/manuals/openmw-vr/

## Controls
OpenMW VR has full motion controls with its own VR control scheme; the complete, current binding reference is in the online manual (link above). Because OpenMW is a full engine, controls and comfort options are extensively configurable.
