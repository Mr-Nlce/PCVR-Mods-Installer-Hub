# Half-Life VR

A full VR conversion of the original **Half-Life** (1998) by **Max Vollmer** (Max Makes Mods). A free mod on Steam that brings Black Mesa into room-scale VR with motion controls.

> This is an **external** mod: it's a free mod on its own Steam store page. Install it from Steam; it requires that you own the original Half-Life.

## What you get
- Full SteamVR support - works with all SteamVR hardware (default bindings for Vive, Index, Oculus Touch, WMR; community/custom bindings supported)
- Highly configurable via a **Config Tool** with 100+ settings for input, movement, anti-nausea, accessibility, and performance
- **Modern Rendition** (AI-upscaled textures, HD models, added female scientists with original voice lines) **or Classic Mode** (a pure, unchanged 1998 look in VR)
- Seated or standing play, free locomotion or teleport
- Physical interactions: touch buttons, grab levers, climb ladders, and grab/throw objects (including playing baseball with headcrabs)

## Requirements
- You must **own the original Half-Life** on Steam (Half-Life 2, Half-Life: Source, or other Source games do **not** count)
- A SteamVR-compatible headset and controllers

## How to install (external)
1. Open the info page (Steam) and install the free Half-Life: VR Mod.
2. Launch it; use the included Config Tool (`HLVRConfig.exe`) to tune settings and pick Modern or Classic mode.

> Still a beta and developed by one modder with help from a few others - expect the odd rough edge.

## Controls
Default bindings ship for Vive, Index, Oculus Touch, and WMR. Everything is remappable through SteamVR controller bindings, and community presets are available. The Config Tool exposes movement, turning, comfort, and accessibility options.
