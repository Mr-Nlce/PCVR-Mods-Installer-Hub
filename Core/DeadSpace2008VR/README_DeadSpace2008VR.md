# Dead Space (2008) VR

## About the Game

Isaac Clarke boards the USG Ishimura to investigate a distress signal. Talemann's DSVR mod puts you in Isaac's suit with stereoscopic first-person VR, tracked arms, roomscale movement, and interactive tools and holograms.

## Install and start

- Use the original **Dead Space (2008)** from **Steam or GOG**. The EA App edition and the remake are unsupported.
- Close the game. **Get Installer** or **Update** opens Talemann's download button for the current Windows setup. The Hub checks the publisher's version automatically. The setup patches the game executable for access to 4 GB of memory and offers an optional HD texture download.
- Run the publisher setup and verify the destination is the original game folder. Select **VR Mod only** or **VR Mod + HD Texture Pack** and follow the setup prompts.
- Start your OpenXR runtime and connect the headset, then use **Start in VR**. If the mod needs support, collect `dsvr.log` from the game folder just after the problem occurs.

## Controls

| Button | Action |
|---|---|
| [[Left Stick]] | Move. Double-tap back for a 180-degree turn when enabled. |
| [[Left Stick Click]] while moving | Sprint until you release the stick. |
| [[Right Stick]] | Turn. |
| [[Right Grip]] (hold) | Aim. |
| [[Right Trigger]] while aiming | Fire the active mode. |
| [[Right Trigger]] (tap without aiming) | Stomp. |
| [[Right Stick Click]] | Toggle fire mode while aiming or show the locator otherwise. |
| [[Left Trigger]] (hold, then release) | Charge and fire Stasis. While aiming in zero gravity, jump. |
| [[Left Grip]] (hold) | Grab with Kinesis. Release to drop. |
| [[Left Grip]] + [[Left Trigger]] | Throw a held object. |
| [[Left Grip]] at a long weapon | Support the weapon with your other hand. |
| [[Left Trigger]] at the left hip | Cycle medkit size. |
| [[Left Grip]] at the left hip | Use the selected medkit. |
| [[Right Grip]] (tap at the right hip) | Draw or holster the weapon. |
| [[Right Grip]] (hold at the right hip) + [[Right Trigger]] | Open the weapon menu and equip the weapon you point at. |
| [[B]] | Reload. |
| [[A]] | Interact or confirm. While aiming, switch to the last weapon. |
| [[X]] | Open the map or go back in a menu. |
| [[Y]] (tap) | Open the inventory. |
| [[Y]] (hold) | Open or close the mod menu. |
| [[Left Menu Button]] or [[Left Stick Click]] + [[Right Stick Click]] | Pause. |
| [[Right Menu Button]] | Open the runtime menu. |
| [[Left Grip]] or [[Right Grip]] in menus | Change tabs. In a submenu, go back. |

Touch your wrist watch to toggle the inventory, tap holograms to interact, and swing the right controller to strike. The publisher's illustrated gameplay, holster, and menu bindings are on the [instructions page](https://dspacevr.com/instructions.html#bindings).

## Removing the mod

Close the game and run the **DSVR** uninstaller from Windows Installed apps. If the original game needs repair after removal, verify its game files through Steam or GOG.
