# Judgment VR

First-person VR conversion by Tensai37 for the Steam release of Judgment. The publisher provides an interactive Windows Setup. The Hub follows the newest public [GitHub release](https://github.com/Tensai30/judgmentvr_1.1/releases), including prereleases, and checks for the installed game and mod before recording its version.

## About the Game

Judgment is a detective action adventure set in Kamurocho. Former lawyer Takayuki Yagami investigates a series of murders while handling street fights, investigations and side cases.

## Before you install

- Install Judgment through Steam and close the game before Setup.
- Start with a clean game folder. The publisher recommends removing other game mods before installing this conversion.
- Keep an active VR runtime and connected headset. Publisher Setup may request Windows administrator approval (UAC).
- Back up saves and modified game files before using another game's mod manager or restoring the base game.

## Install and update

1. Choose [[Install]] on this page. The Hub finds your Steam game and checks the latest [GitHub release](https://github.com/Tensai30/judgmentvr_1.1/releases), including prereleases. If the release API is unavailable, it offers a publisher Setup EXE from your registered Downloads folder; you confirm that file before use. Otherwise, open the publisher releases page, download the Setup and return to the installer.
2. After your confirmation, the Hub prepares the publisher Setup EXE and checks its product version against the release or filename. Read the destination shown by Setup and finish its wizard. The publisher owns installation and removal of its files.
3. The Hub checks the game executable, VR hook, runtime files and Windows installation record before marking the exact installed version.
4. Start Judgment through Steam after setting up your headset runtime.

The 1.2 hotfix expands VR-controller support and uses the runtime resolution. It keeps the game's cinematic cutscene cameras in VR. The default Setup leaves experimental DLSS 5 off; enabling it also requires DLSS in Judgment's graphics settings and a powerful NVIDIA GPU.

## Game settings

Set VSync off, the FPS limit to unlimited and motion blur off. These settings are required by the publisher's VR instructions.

## Controls

The publisher lists these motion actions for first-person combat. Other actions continue to use the game's controller mapping.

| Button | Action |
| --- | --- |
| [[Left Stick]] | Move. |
| [[Right Stick Click]] | Pause or open the smartphone menu. |
| [[Left Hand]] or [[Right Hand]] | Punch forward or swing upward for a light attack. |
| [[Left Controller]] beside the left side of your head | Hold briefly for a heavy attack or kick. |
| [[Both Hands]] | Reach forward, hold until vibration, then pull back to grab. |
| [[Both Hands]] in front of your headset | Guard. |

## Troubleshooting

- If the VR view is absent, confirm that your VR runtime and headset are active and that Setup completed in the Steam game folder.
- If the game or controls behave unexpectedly, remove other game mods and use the publisher Setup's repair path.
- If a required file is missing, consult the Hub installer log and any matching security history; a missing file alone does not prove quarantine.
