# Black & White VR

## About the Game
Raise a Creature, guide your villagers and rule a living island through miracles and your own good or evil deeds.

## Requirements
Your own original Windows PC copy is required; the Hub does not supply or link a game download. Use Locate Game in the Hub or drag runblack.exe into setup.

If patch 1.42 is missing, setup offers official patch 1.10, then 1.20, then unofficial patch 1.42. Each has a separate Enter-to-download and Enter-to-install step; Windows may request administrator approval. Select the shown game folder in each Setup. Skip only steps already installed. A detected 1.42 installation keeps its patches. Start this patched game once in flat, reach the main menu and quit; the Hub can start it after Enter. Do not add patch 1.30, Creature Isle or another graphics wrapper. Publisher Setup checks the exact supported EXE.

Use a 32-bit OpenXR runtime. Virtual Desktop: VDXR selected and SSW disabled. SteamVR: version 2.17 or later and selected as the OpenXR runtime. Steam Frame support is experimental and uses a separate publisher add-on; this Windows installer does not install that add-on.

## Install and start
1. Choose Install in the Hub. Complete the guided patch/flat checks, then install publisher Setup into the detected game folder. If Windows protects the folder, confirm the announced administrator continuation; the Hub retains your selected folder and waits for that setup to finish. Folder permissions are not changed.
2. Use Start in VR in the Hub, then choose Play in VR in the publisher launcher.
3. Alternative: use the Black & White VR desktop shortcut. The launcher's Play, no VR button provides its official temporary Flat / VR switch and restores display settings after the game closes.

Skip the mouse-focused tutorial: choose Skip straight to the Creature select for a new game. Lower Resolution scale in the launcher if performance is poor.

## Controls
| Button | Action |
|---|---|
| [[Right Grip]] | Grab, hold or throw; point and pull to reach distant objects |
| [[Right Trigger]] | Click an object or menu; command your leashed Creature |
| [[Right Stick]] | Zoom up/down; turn left/right |
| [[A]] | Hold to aim a teleport, release to move |
| [[B]] | Cancel teleport; hold and draw a miracle gesture |
| [[Left Grip]] | Grab the land and pull to move |
| [[Left Grip]] + [[Right Grip]] | Turn and zoom the world |
| [[Left Stick]] | Move in your head direction |
| [[Y]] | Hold to open the ring menu |
| [[Menu]] | Open the game menu |
| [[F11]] | Recenter the view |

## Help
The launcher identifies the first missing requirement. Patch 1.42, a working 32-bit runtime and the complete dxwrapper/OpenXR file set are required. Publisher maintenance and reinstall are available through the Hub installer recovery screen.

## Technical details
The publisher adds ddraw.dll, openxr_loader.dll, Black & White VR Mod.exe, the dxwrapper subfolder and its own readme/notices. The start app is Black & White VR Mod.exe in the located game folder. Profiles and saved games are not installed by the Hub.
