# Half-Life 2: VR Mod

The Source VR Mod Team's free, standalone VR conversion of
Half-Life 2 (AppID 658920), Episode One (2177750), and
Episode Two (2177760). All three are distributed through
Steam as separate free games.

## How to install the game

Click "Open in Steam" to open the store page, then click
Install. Launch once to confirm everything works.

## Optional add-on: HL2VRU "Unleashed"

HL2VRU is a community fork by Vittorio Romeo that adds:

- Dual wielding (any weapon, any hand)
- Universal melee (physical attacks with any weapon)
- Physical jumping
- Virtual stock for stable two-handed aiming
- Grip-holster mode
- Weapon weight simulation
- Difficulty tweaks (damage / recoil / spread)

The "Install Unleashed add-on" button on this page handles
the install once the base mod is in place. The add-on works
with all three games (base + Episode One + Episode Two).

To remove HL2VRU later: right-click "Half-Life 2: VR Mod" in
your Steam library, Properties -> Installed Files -> "Verify
integrity of game files". Steam re-downloads the original
files and the add-on is gone.
