# Mafia II (Classic) VR

## About the Game

Play Vito Scaletta's story in Empire Bay with stereoscopic VR and tracked hands. The mod lets you aim, reload, throw punches and grip the steering wheel with motion controllers.

## Install and play

1. Install **Mafia II (Classic)**. The publisher supports the Steam and compatible Complete/Digital Deluxe builds with `mafia2.exe` version 1.0.0.1. Mafia II: Definitive Edition uses a different executable.
2. Start the game once on the desktop, then close it. In the Hub, choose **Install**. The Hub downloads the publisher setup, or you can supply its ZIP in recovery.
3. The Hub copies the `pc` folder path to your clipboard. Press Enter, approve the required Windows administrator prompt, then paste the path into the publisher's game-folder field with Ctrl+V or right-click and choose Paste. If pasting is unavailable, type the displayed path. The setup patches the executable and keeps an original copy. On updates, the Hub saves a dated copy of your prior VR settings.
4. Connect your headset and use **Start in VR** to open **M2VR Launcher**. Choose the appropriate OpenXR/runtime and controller profile there. The mod needs a Vulkan-capable GPU and the [Visual C++ 2015–2022 Redistributable (x86)](https://aka.ms/vc14/vc_redist.x86.exe).
5. To remove the VR mod, close the game and launcher, then use **Mafia II Classic VR MOD** in Windows Installed apps. The publisher uninstaller restores the original executable.

## Controls

| Button | Action |
| --- | --- |
| [[Left Stick]] / [[Left Stick Click]] | Walk / run |
| [[Right Stick]] | Turn or move the cursor in menus |
| [[Right Stick Click]] + hand movement | Switch weapon |
| [[Right Trigger]] | Shoot or confirm in menus |
| [[Left Trigger]] | Vault or dodge |
| [[Left Grip]] | Support the weapon, grab a magazine or work the bolt |
| [[Right Grip]] + [[Right Trigger]] | Light punch without a weapon |
| [[Left Grip]] + [[Left Trigger]] | Heavy punch without a weapon |
| [[Right Grip]] + [[Right Trigger]] | Prepare and release a grenade or Molotov |
| [[A]] | Interact, take cover, or confirm in menus |
| [[B]] | Back in menus |
| [[X]] | Tap to enter or exit a car, double-tap to break the window, or tap repeatedly to pick the lock. Hold to open the main menu |
| [[Y]] | Map |
| [[Left Grip]] / [[Right Grip]] | Hold the steering wheel. Use [[Left Stick]] for stick steering |
| [[Right Trigger]] / [[Left Trigger]] | Accelerate / brake and reverse |
| [[Right Grip]] + wrist turn at the radio | Change station |
| [[Left Menu Button]] / [[F10]] | Recenter the camera |
