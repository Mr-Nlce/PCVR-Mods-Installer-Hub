# Shipbreaker VR

**ShipbreakerVR** by **Raicuparta** - a VR camera mod for **Hardspace: Shipbreaker**.

> This is an **external** mod: the Hub links you to Raicuparta's itch.io page. Download the RaiManager installer there, run it, and point it at your Hardspace: Shipbreaker install. Once it's installed, the Hub detects it and can launch the game for you.

## Features
This is a simple mod that enables a VR camera via a key binding. The UI and aiming direction are detached from the camera for a more comfortable experience. There are **no motion controls** - you play with your normal gamepad or mouse & keyboard. You will need to take your headset off at times and toggle VR on and off to be able to get through some parts of the game. Some other parts might not work even when you toggle VR off. Some people have played large portions of the game like this, but some features are still a bit broken.

## Requirements
- A copy of **Hardspace: Shipbreaker** (Steam, GOG, Epic, or Microsoft Store)
- A PC ready for PCVR (this does **not** work on standalone headsets)
- An OpenXR-compatible headset and runtime (SteamVR, Oculus, or WMR)
- For Quest over Virtual Desktop, set **SteamVR** as your OpenXR runtime; for official Link / Air Link, set **Oculus** as your OpenXR runtime

## How to install (external)
1. Open the info page (itch.io) and download ShipbreakerVR (name-your-price; free is fine). The itch.io app is recommended so you get automatic updates.
2. Run `RaiManager.exe` (or click **Open** in the itch.io app) and follow the instructions in the installer.
3. Launch the game as usual.

> To uninstall: run `RaiManager.exe` again and use the uninstall option. Your game files and save progress are untouched.

## How to play
- Start the game as usual.
- Wait until you're fully in game, floating in space.
- **Press F3 to turn on VR.** If you reach a part where VR isn't working (for example when you need to interact with the UI), press **F3** again to disable VR and play that part with mouse & keyboard or gamepad.

## Performance
Two extra key bindings help on lower-end hardware:
- **Press F5** to enable ultra low quality mode (lower than the in-game options allow).
- **Press F6** to disable all lights in the current scene. Looks sad, but can give you a performance boost.

## Controls
Gamepad (or mouse & keyboard) - the same controls as the flat game. The mod adds keyboard toggles only:
- `[F3]` toggle VR camera on/off
- `[F5]` ultra low quality mode
- `[F6]` disable scene lights (performance)
