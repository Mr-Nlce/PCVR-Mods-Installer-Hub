# Resident Evil Code: Veronica X VR

## About the Game

Claire and Chris Redfield fight to survive Umbrella experiments on Rockfort Island and in Antarctica. Explore, solve puzzles and conserve ammunition in this classic survival horror adventure.

## Install and Start

1. Use Start in VR in the Hub. The native port opens with --vr and your selected ISO.
2. Start an OpenXR runtime first. In the port launcher press PLAY. The publisher tested Quest 2 with Virtual Desktop / VDXR; other headsets remain unverified by the author.
3. In OPTION > ENHANCED SETTINGS > VR choose snap turn, comfort vignette, sight and resolution.

Supply your own Resident Evil Code: Veronica X PS2 NTSC-U disc image, SLUS-20184, as an ISO. The image stays in its original location and is read directly, without extraction or another multi-gigabyte copy. Other base-game regions, Dreamcast and HD console editions are not supported. The port can import language data from another owned language disc with [[F9]]; the base US ISO is still required.

Default runtime folder: C:/Games/Resident Evil Code Veronica X VR. Choose another full folder during setup. Saves and settings remain in save; your disc path is remembered in save/recvx.ini. If the ISO moves, run setup to choose its new location. Optional community textures may be placed in textures; none are downloaded automatically.

## Controls

| Button | Action |
| --- | --- |
| [[Left Stick]] | Walk in the direction you look. |
| [[Left Stick Click]] while moving forward | Toggle running until you stop. |
| [[Left Trigger]] (hold) | Run; while aiming twin guns, fire the left gun. |
| [[Right Stick]] left / right | Snap turn (disabled on stairs). |
| [[Right Grip]] (hold) | Raise and aim the gun with your hand. |
| [[Right Trigger]] | Fire the right-hand gun. |
| [[Left Grip]] at the gun | Two-handed support grip. |
| [[Left Grip]] with free left hand | Draw knife; swing to cut. |
| [[Left Grip]] at the belt | Take an ammo box; hold and bring it to the gun to reload. |
| [[A]] | Interact, open doors, pick up items, examine or confirm. |
| [[B]] | Cancel / back; while holding a gun, drop its magazine. |
| [[Y]] | Inventory. |
| [[X]] / [[Right Stick Click]] | Map. |
| [[Right Stick]] forward / back in sniper scope | Zoom. |
| [[Menu]] | Select. |
| [[System Button]] (long press) | Recenter through your headset runtime. |
| [[F9]] | Import another owned language disc in the PC window. |

## Updates and Removal

Use the Hub installer for the latest official Windows VR package. A failed copy or incomplete package does not mark the update complete. Setup backs up replaced files; Uninstall now removes only unchanged Hub-owned files and restores originals. Changed user settings, saves, textures, disc images and unrelated files are kept.
