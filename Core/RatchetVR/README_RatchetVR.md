# Ratchet & Clank VR

A **free** Unreal Engine fan project by **Rybread69** that recreates worlds from the first four PS2 Ratchet & Clank games in first-person VR. It is a growing work-in-progress: explore the classic planets, smash crates, collect Bolts, use gadgets and fire familiar weapons.

**Motion controls.** There is no combat yet, so it currently plays like an interactive museum of classic Ratchet & Clank memories rather than a full game. New content is added over time.

## What you get
- First-person VR recreations of worlds from the first four games (e.g. Novalis, Aridia, Oozla)
- Crate smashing, Bolt collecting, gadgets and familiar weapons
- A free, standalone build - not on Steam, no base game required

## How to install
1. The installer opens the **Google Drive download** in your browser (the itch.io page is linked too, for info).
2. Download **`RatchetVR.rar`** (~8 GB). If Drive can't virus-scan a file that large, choose **Download anyway**.
3. Back in the installer window, **drag-and-drop the `.rar`** (or paste its full path) and press Enter.
4. The installer extracts it (7-Zip is auto-installed if missing) to `C:\Games\Ratchet VR` and creates a desktop shortcut. The wrapping `RatchetVR` folder is flattened so `RatchetVR.exe` sits at the game root.

## How to launch
Start your **VR runtime** first, then either:
- Use the Hub's **Start in VR** button (runs `RatchetVR.exe`), or
- Use the desktop shortcut **Ratchet VR**.

## Controls
- **[[Left Stick]]:** move
- **[[Right Stick]]:** turn
- **[[A]]:** jump (up to triple jump)
- **[[X]]:** jetpack
- **[[Left Trigger]]:** swing hook / grapple
- **[[Right Trigger]]:** interact / use weapon
- **[[Left Grip]]:** grab / gadget
- **[[Menu]]:** menu / recenter

Since the project is early and evolving, controls could change over time.
