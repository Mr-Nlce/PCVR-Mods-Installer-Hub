# Dungeon Keeper 2 VR

## About the Game

LoVeMaKeRz puts the dungeon on a table in a stone room. Point, grab the table and possess creatures in first person. This package requires the original **Dungeon Keeper 2 v1.70 `DKII-DX.exe`**; other game builds are rejected before any mod files are copied. The publisher validated Meta Quest 3 with Virtual Desktop; other OpenXR headsets are not yet confirmed by the publisher.

## Install and start

The Hub downloads the current stable publisher ZIP, checks the version and required files, then copies the publisher's `DK2VR` folder and `DKII_VR.cmd` into your game folder. Existing `DK2VR.ini`, saves and unrelated files stay. Unsigned runtime files may trigger antivirus warnings; a missing file is not proof of quarantine.

**1. Use Start in VR in the Hub.** Start your OpenXR runtime first. Alternatively, run `DKII_VR.cmd` from the game folder. Restart the game after changing its resolution, or selection lines and interface elements may appear incorrectly.

## Controls

| Button | Action |
| --- | --- |
| [[Left Stick]] | Move the map at the table; move in possession. |
| [[Left Stick Click]] | Open/close the VR keyboard at the table; run in possession. |
| [[Left Grip]] | Grab the table. |
| [[Right Trigger]] | Left click with the laser at the table; attack or use a skill in possession. |
| [[A]] | Right click at the table; next skill in possession. |
| [[B]] | Previous skill in possession. |
| [[Right Stick]] | Turn/zoom the dungeon; turn in possession. |
| [[Right Stick Click]] | Recenter at the table. |
| [[Right Grip]] | Grab the table. |
| [[X]] | Space at the table; leave possession. |
| [[Y]] | Escape at the table. |
| [[F2]] / [[F3]] / [[F4]] | Minimap mode / game panel / VR HUD. |
| [[F5]] / [[F8]] | Reload `DK2VR.ini` / recenter. |

The publisher's in-game Controls wall has hand-specific and French/English layouts. The Options wall changes primary hand, turning, table size and other preferences.

## Update and removal

Updates use the same full publisher ZIP; Hub ownership records which files it copied and backs up earlier files of the same names. **Uninstall now** removes only unchanged Hub-owned files and restores those earlier files. Saved games, personal settings and unrelated files remain. After a crash that leaves temporary VR files in the game folder, run the publisher's `DK2VR\RESTAURER_JEU_ORIGINAL.cmd`.
