# Content Warning VR Installer

Ready to become SpöökFamous in VR? CWVR by DaXcess transforms Content
Warning into a fully fledged 6DOF VR experience with motion controls.
Powered by Unity's OpenXR plugin, so it works with a wide range of
headsets, controllers and runtimes (Oculus, Virtual Desktop, SteamVR and
more).

**Motion sickness warning:** due to the nature of Content Warning (and
the occasional jumpscare), this mod may cause motion sickness.

## What it installs
- **BepInEx** — mod loader
- **CWVR** — VR mod with full motion controls

All packages are downloaded directly from Thunderstore. Running the installer again checks for updates automatically.

## Requirements
- Content Warning owned on Steam
- SteamVR or Virtual Desktop installed

## How to use
Click **Install Mod** on the game tile or detail page and follow the prompts.

The installer shows whether the current mod version is deprecated. If deprecated, use Option 2 (pinned depot build with CWVR 1.2.0).

Controls can be fully rebound in Settings → Controls at any time, even mid-game.

## Configuring the mod

Change settings from inside the game: launch with the mod installed (**Start in VR** in the Hub or via Steam), go to
the main menu -> Settings -> **Mods**. Settings can be changed mid-game; no
restart or rejoin needed.

## Tips

- **Hot switching:** in the main menu, press **F8** to switch between VR and
  flatscreen (this overrides any config/CLI option). On failure it shows a
  popup with access to logs, so troubleshooting needs no game restart
- Only Oculus and Index controllers have bindings out of the box — other
  controllers can be rebound in Settings -> Controls
- **Multiplayer:** works in lobbies with VR players, non-VR players, and
  even vanilla (unmodded) players. The host does **not** need the mod for
  VR players to see each other's hand movements (vanilla players can't see
  hand movements)

## Known issues
- Some settings may not apply correctly on first launch — restart the game if VR doesn't activate
- Content Loader workshop mods may conflict with CWVR
