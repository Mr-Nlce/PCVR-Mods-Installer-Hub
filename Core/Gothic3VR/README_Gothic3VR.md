# Gothic 3 VR

## About the Game

Explore Myrtana with tracked hands, physical sword combat, archery, spell aiming and room-scale movement. Gothic 3 VR supports the original Gothic 3 Classic from Steam, GOG and retail with the publisher's native patch profile.

## Install and play

1. Start Gothic 3 Classic on the desktop once, then close it and open **Install** in the Hub.
2. Choose **1** to let the Hub copy the original game. Use `C:\Games\Gothic 3 VR`, the suggested folder under your previous depot location, or enter another full destination path. Confirm the source and destination before copying. If you already have a separate copy, choose **2** and drop or paste its `Gothic3.exe`. You can also confirm a remembered copy with Enter.
3. Confirm the separate folder in publisher setup and keep **VR core** selected. Setup can download and apply the four required patches. The Community Patch alone is about 1.6 GB. DXVK / FFR, menu artwork and music are optional.
4. Choose **Start in VR** in the Hub to open the Gothic 3 VR launcher. Under **Camera & controls → OpenXR runtime**, select the option that matches how your headset is connected. The wrong runtime can leave the VR controllers unresponsive. Connect both controllers, open **Headset setup → Start headset setup**, and select **Test controls** before choosing **Save and launch**.
5. For removal, use **Gothic 3 VR** in Windows Installed apps. The publisher uninstaller handles its owned files and backups.

When patch downloads need manual recovery, follow the publisher guide. The order is Community Patch 1.75.14, Update Pack 1.04.11, Update Pack 1.05.10 Public Beta and Parallel Universe Patch 1.1.1.

| Headset connection | OpenXR runtime in the launcher |
| --- | --- |
| Virtual Desktop | Virtual Desktop / VDXR |
| Quest Link or Air Link | Meta Quest Link / Air Link (64-bit host) |
| SteamVR | SteamVR (OpenXR) |

## Controls

| Button | Action |
| --- | --- |
| [[Left Stick]] | Move |
| [[Left Stick Click]] | Tap to sprint |
| [[Right Stick]] | Turn or select an entry in the radial |
| [[Right Stick Click]] | Tap to open the radial |
| [[A]] / [[X]] / [[B]] | Confirm / cancel / change page in the radial |
| [[B]] | Draw or sheath your weapon outside the radial |
| [[X]] | Open inventory outside the radial |
| [[Y]] | Double-tap to sneak after learning the skill |
| [[Left Trigger]] | Double-tap to use a healing potion |
| [[Right Trigger]] | Interact, cast or fire a crossbow. Hold and release the bowstring |
| [[Right Grip]] | Quick Loot or block with a raised weapon |
| [[Left Grip]] | Attach your support hand or block with a raised shield |
| [[Left Menu Button]] | Open the main menu or go back |
| [[Left Stick Click]] + [[Right Stick Click]] | Hold for 0.5 seconds to recenter |
| [[X]] + [[Y]] | Hold briefly to return from animal form |
