# Stanley Parable VR

**StanleyVR** by **Raicuparta** - a VR mod for **The Stanley Parable: Ultra Deluxe**, playable start to finish with full motion control support.

> This is an **external** mod: the Hub links you to Raicuparta's itch.io page. Download the RaiManager installer there, run it, and point it at your Stanley Parable install.

## What you get
- Full motion-control VR for the complete Ultra Deluxe experience
- Playable from start to finish (expect a little jank - this one is less polished than Raicuparta's flagship mods)

## Requirements
- A legitimate, up-to-date copy of **The Stanley Parable: Ultra Deluxe** (Steam). The old, non-Deluxe version is **not** compatible.
- A PC ready for PCVR
- An OpenVR-compatible headset (Quest via Link/Air Link/Virtual Desktop/ALVR, Rift, Index, Vive, WMR)
- **VR motion controllers** - not playable with a normal gamepad

## How to install (external)
1. Open the info page (itch.io) and download StanleyVR (name-your-price).
2. Run `RaiManager.exe` (or use the itch.io app for automatic updates) and follow the installer.
3. Launch The Stanley Parable: Ultra Deluxe as usual; it starts in VR.

> RaiManager versions may keep BepInEx beside the downloaded package and reference it through `doorstop_config.ini`. The Hub recognises both that layout and a normal in-game BepInEx install. If `targetAssembly` contains an absolute path, do not move or delete that RaiManager/package folder; reinstall from a permanent location instead.

> To uninstall: run `RaiManager.exe` again and click the uninstall button. Your game files and progress are untouched.

## Controls
Motion controls only. Standard Raicuparta VR scheme; the game is light on mechanics, so it's mostly look, move, and interact.
