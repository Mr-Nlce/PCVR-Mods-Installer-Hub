# DREDGE VR Mod Installer

Automated installer for DredgeVR by xen-42.

## What it installs
- **Winch v0.6.1** — DREDGE mod loader
- **DredgeVR (latest)** — full VR mod with motion controls

## Features

- 6DOF tracking and full motion-controller support
- The game is playable start to finish in VR

## Requirements
- Windows 10/11
- Steam with **DREDGE** installed (the mod uses SteamVR, so Steam is
  required; in theory it works on non-Steam copies but that's untested)
- SteamVR installed
- Internet connection (for mod download)

## In-Game
- Launch DREDGE normally via Steam — SteamVR starts automatically
- Built-in bindings for Oculus and Valve Index
- Other controllers may need manual SteamVR binding setup in SteamVR Settings
- Known issue: ocean and ice shaders are not perfect in VR (depth buffer limitation — does not affect gameplay)
- Settings configurable via JSON file in `Mods/xen.DredgeVR/`
