# Firewatch VR

**Two Forks VR** by **Raicuparta** - a full VR mod for **Firewatch**. The whole game is playable in VR with room-scale tracking, motion controls, and multiple comfort options.

> This is an **external** mod: the Hub links you to Raicuparta's itch.io page. Download the RaiManager installer there, run it, and point it at your Firewatch install.

## What you get
- Full 6DOF room-scale VR with motion controls
- Left-handed mode and multiple comfort options
- Optional openvr_fsr support for a performance boost (edit `Firewatch\Firewatch_Data\Plugins\openvr_mod.cfg`)

## Requirements
- A compatible version of **Firewatch** (the mod targets a specific build, currently 1.1.2 - Steam, GOG, or Game Pass)
- A PC ready for PCVR (this does **not** work on standalone headsets)
- An OpenVR-compatible headset (Quest via Link/Air Link/Virtual Desktop/ALVR, Rift, Index, Vive, WMR)
- **Steam + SteamVR installed** (even if you own the game on GOG or Game Pass)
- **VR motion controllers** - the mod is not playable with a normal gamepad

## How to install (external)
1. Open the info page (itch.io) and download Two Forks VR (name-your-price; free is fine).
2. Run `RaiManager.exe` (or use the itch.io app for automatic updates) and follow the installer.
3. Launch Firewatch as usual; it starts in VR.

> To uninstall: run `RaiManager.exe` again and click the uninstall button. Your game files and save progress are untouched.

## Controls
Motion controls only. The in-game tutorials teach the VR buttons; if you already finished them, disable the "hide interface" option to see the button prompts. The tool picker opens with a controller button, and the radio is on the non-dominant hand's trigger. Left-handed mode is available.
