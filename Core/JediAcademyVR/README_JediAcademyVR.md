# Jedi Knight: Jedi Academy VR

**JKXR** by **Team Beef** - a VR port of **Star Wars Jedi Knight: Jedi Academy**. Build your own lightsaber, choose your path through the academy, and fight with motion-controlled saber and Force powers in full 6DOF VR.

> This is an **external** mod: the Hub links you to Team Beef's JKXR project. The mod is an engine port and needs the original game's assets.

## What you get
- Motion-controllable lightsaber and Force powers
- Third-person lightsaber combat blended with first-person blaster/exploration
- Build-your-own-saber and the non-linear level path of Academy
- **Team Beef Directors Cut (TBDC)** on by default: original-style fast, aggressive enemy speeds, with raised projectile speed and gun power to feel more movie-canon
- Hidden cheat menu on the Datapad (**Y button**): spawn lightsabers, full health, all weapons
- Sandbox mode via the "NPCsp Mod" add-on

## Requirements
- You must **own Jedi Knight: Jedi Academy** (Steam) - JKXR is an engine port and ships no game assets; it needs the original `.pk3` files
- A PCVR-ready setup with an OpenXR headset
- **Do not** run via the SteamVR OpenXR runtime - use your headset's native runtime (Oculus, etc.)

## How to install (external)
1. Open the info page and grab the latest JKXR release with Jedi Academy support for PCVR.
2. Follow Team Beef's instructions to point the port at your Jedi Academy `GameData\base` assets.
3. Launch in VR per the project's PCVR guide.

> Note: historically the Academy build was the later, sometimes Patreon early-access target while Outcast was the public release. Check the project page for the current PCVR build status.

## Controls
The full, up-to-date binding chart lives **in-game**: open **Controls -> JKXR HELP -> Show Control Defaults**. There are also tutorial videos in that menu for the special VR features (saber throw, Force powers, etc.).
