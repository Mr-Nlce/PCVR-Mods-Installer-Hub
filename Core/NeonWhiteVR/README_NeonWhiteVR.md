# Neon White VR

**HeavenVR** by **Raicuparta** - a full VR mod for **Neon White**, the fast-paced speedrunning card-shooter. Playable start to finish in 6DOF VR with motion controls.

> This is an **external** mod: the Hub links you to Raicuparta's itch.io page. Download the RaiManager installer there, run it, and point it at your Neon White install.

## What you get
- 6DOF stereo VR camera with motion controls
- Smooth and snap turning, handedness options
- Adds weapon models (the flat game didn't have them)
- Optional animated player body (handy for LIV recording)
- Fine-tuning options for the VR controls
- VR-specific leaderboards (Steam only)

## Requirements
- A legitimate, up-to-date copy of **Neon White** (Steam)
- A PC ready for PCVR
- An OpenXR-compatible headset (Quest via Link/Air Link/Virtual Desktop/ALVR, Rift/Rift S, Index, Vive, WMR)
- **VR motion controllers** - not playable with a normal gamepad

## How to install (external)
1. Open the info page (itch.io) and download HeavenVR (name-your-price; free is fine).
2. Run `RaiManager.exe` (or use the itch.io app for automatic updates) and follow the installer.
3. Make sure the correct **OpenXR runtime** is selected: Oculus for Quest Link/Air Link, SteamVR for Virtual Desktop.
4. Launch Neon White as usual; it starts in VR.

> RaiManager versions may keep BepInEx beside the downloaded package and reference it through `doorstop_config.ini`. The Hub recognises both that layout and a normal in-game BepInEx install. If `targetAssembly` contains an absolute path, do not move or delete that RaiManager/package folder; reinstall from a permanent location instead.

> To uninstall: run `RaiManager.exe` again and click the uninstall button. Your game files and progress are untouched.

## Controls
Motion controls only - fast, snappy aiming suits Neon White's speedrun gameplay. Smooth/snap turning and handedness are configurable in the mod's options.
