# Mass Effect 1 Legendary Edition VR

## About the Game

Follow Commander Shepard aboard the Normandy in the first Mass Effect. Both mods below require the Legendary Edition. The gameplay video shows the Gamepad mod.

## Choose a VR mod

| Installer choice | What it adds |
| --- | --- |
| 1. MEVR by dnehring | OpenXR, tracked weapons and holsters, hand gestures and a VR menu. Start the base game once before installing. |
| 2. MELE-VR by dhalcyon | Gamepad controls, stereoscopic and alternate-eye VR modes. |

The reviewed MEVR Windows package is **0.2.0**. MEVR Setup parks the Gamepad renderer and restores it when MEVR is removed. To play MEVR, start your OpenXR runtime, then use **MEVR** on the Hub's game page. The installer keeps your graphics settings.

## Controls

| Button | Action |
| --- | --- |
| [[Left Stick]] | Move. |
| [[Right Stick]] | Turn. |
| [[Right Trigger]] | Fire. |
| [[Right Grip]] | Draw and hold a weapon at its holster. Release at the holster to put it away. |
| [[Left Grip]] | Support the weapon with both hands. |
| [[Left Trigger]] | Open the weapon wheel. |
| [[Right Stick Click]] | Hold for the game's power wheel. Double-click to recenter. |
| [[Left Stick Click]] | Toggle crouch. |
| [[A]] | Interact. Hold to sprint. |
| [[B]] | Hold to direct the squad. Double-tap to call them back. |
| [[X]] | Choose a power. |
| [[Y]] | Use medi-gel. |
| [[Left Stick Click]] + [[Right Stick Click]] | Hold to open the VR menu. Tap to capture a headset image. |

Button availability varies by controller profile. See the [publisher's MEVR controls reference](https://github.com/dnehring/MEVR/blob/main/docs/controls.md).
