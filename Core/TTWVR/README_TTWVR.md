# A Tale of Two Realities

## About the Game

Explore the Capital Wasteland and Mojave in the same playthrough with Tale of Two Wastelands. KUPOkinz's TTWVR adds motion controls, hand-operated weapons, a wrist-mounted Pip-Boy and experimental multiplayer. For the Mojave campaign alone, choose option 2 on **Fallout: New Vegas**.

## Requirements

- Windows and an English copy of **Fallout: New Vegas Ultimate Edition**. For both campaigns, also install the **English, uncut Fallout 3 Game of the Year Edition**. A German Uncut patch can restore violence while leaving the German game data in place. TTW requires the English game data.
- Use writable game folders outside **Program Files**. For New Vegas, the Hub can create a separate copy. Drop an empty folder into the installer, paste a full path such as `D:\VR Games\New Vegas TTWVR`, or press Enter for the suggested location. You can also select an earlier Hub copy for repair. Setup checks the required game archives and asks before copying or restoring files.
- The combined route builds a portable **Mod Organizer 2** profile or accepts an existing one. The publisher conversion builds TTW data on your PC and can take an hour or longer. Keep roughly 20 GB free for the conversion in addition to both original installations.
- **Discord download** for TTWVR, **ModPub** for the combined conversion and YUPTTW update, and **Nexus** for missing utilities. Sign in as requested. The Hub names each file, opens its source after Enter and accepts the complete archive by drag-and-drop. MO2, xNVSE and the Stewie settings preset download from GitHub.

If you already have English Fallout 3 GOTY, drop its game folder at the Fallout 3 prompt. Otherwise choose **D**. In Steam Console, paste the copied command and wait for **Depot download complete**. Return to the Hub and press Enter. The Hub finds the download automatically. If Steam saved it under Program Files, press Enter to copy the files to the suggested folder or choose a different empty folder. If Steam denies access, use an English GOTY installation from a store where you own it.

## Install from the Hub

1. Install the English editions and all DLC. Open each original launcher once, accept hardware detection, then exit. Keep both games in writable folders. A clean game profile avoids conflicting graphics, animation and Pip-Boy mods.
2. Choose **Install** on this page. For a fresh combined profile, press Enter when the Hub offers to build it. The Hub prepares the portable MO2 instance and sets the New Vegas folder. When MO2 opens, follow the checklist below.
3. For the combined route, download **Tale of Two Wastelands** from **Main files** on ModPub. Press Enter to open the converter and choose **Yes** at the Windows UAC prompt. Use the three paths shown in the Hub. Put the selected English depot or its copy in **Fallout 3** and any separate New Vegas copy in **Fallout: New Vegas**. Replace the prefilled Steam paths when they differ. **Tale of Two Wastelands** is the output folder. The Hub copies the New Vegas path to the clipboard. Then select **YUPTTW** under **Main files** on ModPub when prompted. Keep `TTWVR.zip` for step 5.
4. Press Enter to open **Nexus Mods**, select the file named by the installer, then choose **Manual Download**. The **TTWNVSE** download can arrive as a **ROOGNVSE** archive. When the installer asks for the archive, drop it anywhere in the Hub window, choose **Browse…**, or press Enter to search Downloads and confirm the result. The Hub installs the package into the selected profile and handles the 4 GB patcher. For a new combined profile, continue the flat game check after reaching the main menu.
5. Press Enter to open the Tale of Two Realities Discord invite. Join, return to the installer and press Enter to open **#announcements**. Scroll to the bottom and download `TTWVR.zip` from the newest release message. Drop the complete archive when asked, or press Enter to search Downloads and confirm the result. The Hub reads the version from the selected archive when available. For older archives without a version, type the version from the corresponding Discord message. Keep the optional performance setup out of the initial VR profile.

## Update TTWVR

Close Fallout and MO2. On the game page, choose **Update** or **Reinstall / update mod**. When setup verifies your saved MO2 profile, press Enter to update TTWVR only. Open Discord when prompted and drop the latest complete `TTWVR.zip` into the installer. The update keeps your converted TTW files, dependencies, MO2 profile, saves and calibration.

### Required MO2 setup for a new profile

1. If **Category Setup** opens, click **Do Nothing**. You can skip the tutorial and Nexus sign-in.
2. Select **Default** in the main profile list. Open **Profiles** with [[Ctrl]] + [[P]], select **Default**, and tick **Use profile-specific Game INI Files** and **Use profile-specific Save Games**. Close **Profiles**.
3. Choose **Fallout Launcher** at the top right and click **Run**. If MO2 shows **INI file is read-only**, choose **Clear the read-only flag**, the first option. **Allow the write once** restores the flag and can bring the prompt back.
4. Wait for the Fallout Launcher menu. If hardware detection appears, click **OK**. Then click **Exit**. This step only checks that the launcher opens. Close MO2 if it is still open, return to the Hub and type **Y**. If MO2 closed after starting the launcher, the Hub checks the saved profile and can resume the same step. If the launcher never opened, type **R** to retry.

## What's new in v1.1.5
- Assign weapons and items to up to eight body holsters from the hotkey wheel, which opens with [[Right Stick Click]]. Select a numbered slot and press [[Trigger]] to toggle its holster. Hold a grip for three seconds to move the holster, or use the other hand to resize it.
- Select the **Custom** radio station to play MP3s from the mod's TTWVR/music folder.
- Multiplayer improves the server browser and synchronization of NPCs, doors, keys and locks. It also fixes incorrect player names and visual glitches after fast travel. [v1.1.5 release notes](https://discord.com/channels/1570233209462194208/1570238629832564858/1571149761212321864)

## Earlier v1.1.4 changes

- Multiplayer VATS now runs in real time, in the style of Fallout 76.
- Use or equip items in your hands by holding the corresponding face button. Seated calibration is less likely to trigger sneaking.
- Turn speed can be set from 0 (off) through 50 (default) to 100 (double). Choose which hand can open the loot menu, or disable it.
- Ejected ammo stays in the world for pickup. Purple markers identify the ammo pouch, hip holsters and stims so you can reposition them.
- Includes multiplayer character appearance fixes and optimizations. [Full release notes](https://discord.com/channels/1570233209462194208/1570238629832564858/1570515912820265081)

## Start in VR

1. Open your VR runtime while standing upright. On Quest with Virtual Desktop, enable **Forward Tracking Data** in Streaming settings and use VDXR. For SteamVR, start SteamVR before launching.
2. Choose **Start in VR** in the Hub. The Hub runs `ModOrganizer.exe` with the selected profile and the patched New Vegas executable. That profile supplies the mod's virtual game files.
3. In the game, sit or stand as desired. Extend your arms straight ahead and hold [[Left Trigger]] + [[Right Trigger]] until you feel the calibration vibration. Repeat when changing your height.

## Controls

### Movement and menus

| Button | Action |
| --- | --- |
| [[Left Stick]] | Move |
| [[Right Stick]] left or right | Turn |
| [[Right Stick]] down | Crouch or sneak |
| [[Right Stick]] up | Jump |
| [[A]] or [[X]] | Activate with the pointing hand |
| [[B]] | VATS |
| [[Right Stick Click]] + [[Right Stick]] | Hold to select a favorite, then release |
| [[Left Stick Click]] | Wait |
| [[Y]] | Pause |
| [[Left Grip]] or [[Right Grip]] | Grab items |
| [[Right Stick]] | Scroll a loot menu |
| Hold [[Left Stick Click]] | Open the console |

### Weapons and items

| Button | Action |
| --- | --- |
| [[Left Grip]] or [[Right Grip]] | Draw from either shoulder, take an item from a holster or grip a weapon |
| Hold [[X]] or [[A]] for the hand holding the item | Use or equip the item |
| [[Left Trigger]] or [[Right Trigger]] | Fire, operate weapon parts or change scope zoom |
| Hold [[Left Trigger]] or [[Right Trigger]] | Smooth aim with a firearm. Heavy attack or block with a melee weapon |
| [[A]] or [[X]] | Drop ammo. With a bolt or slide pulled back, lock it |
| [[Left Grip]] + [[X]] or [[Right Grip]] + [[A]] | Save held ammo |
| Hold [[A]] or [[X]], then [[Left Grip]] or [[Right Grip]] | Pump the action |
| [[A]] or [[X]], then flick your wrist | Open or close a loading gate |
| [[Swing weapon]] | Melee attack or gun bash |
| [[Left Stick]] + [[Left Trigger]] or [[Right Trigger]] | Move into a heavy attack for a special melee attack |
| Hold [[Left Grip]] or [[Right Grip]] with an empty hand | Punch or offhand bash |
| [[Left Grip]] or [[Right Grip]] with the free hand | Pull the pin or prime an explosive |
| Release [[Left Grip]] or [[Right Grip]] | Throw, or release loot over a shoulder to stow it |
| Hold [[Left Trigger]] or [[Right Trigger]] near ammo pouch | Change ammo type |
| Hold [[Left Grip]] or [[Right Grip]] for three seconds on a marker | Reposition a holster, ammo pouch or stim slot |
| Hold [[Left Grip]] or [[Right Grip]] and flick back | Pull a pointed-at item with the gravity gloves |
| [[Left Grip]] or [[Right Grip]], then [[Left Trigger]] or [[Right Trigger]] | Grab and activate a Live-Stim before using it |
| Hold [[A]] during conversation | Speak, then release |

### Wrist-Boy

| Button | Action |
| --- | --- |
| [[Right Trigger]] near the Wrist-Boy | Turn it on or off |
| [[Right Trigger]] + [[Left Grip]] or [[Right Grip]] | Switch categories |
| [[Left Grip]] or [[Right Grip]] | Switch pages |
| [[Left Trigger]] near the Wrist-Boy | Open or close the paused Pip-Boy |
| Hold [[Left Trigger]] near the Wrist-Boy | Flashlight |
