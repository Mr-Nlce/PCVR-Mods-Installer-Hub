# Resident Evil 5 VR

## About the Game

Join Chris Redfield and Sheva Alomar in a co-operative action horror adventure through Kijuju. Fight infected enemies, manage ammunition and uncover a new bioterror threat.

## Install and Start

1. Start SteamVR or connect Virtual Desktop with VDXR, then use Start in VR in the Hub. Use Type D controls and Windowed display.
2. The installer starts new configurations with First person camera, Steady hands and Start in VR automatically enabled. If you already have a configuration, open the mod menu with [[Insert]] or both stick clicks to change your choices.
3. To use 6DOF arms, enable them and follow the T-pose calibration. When playing Sheva, enable the left-handed character option first.

The publisher recommends the [4GB patch](https://ntcore.com/4gb-patch/) for re5dx9.exe to reduce memory stutter. The tool creates re5dx9.exe.Bak; Steam verification can undo the patch. This setup does not modify your EXE. Meta's native OpenXR runtime is unsupported; use SteamVR or VDXR.

The VR ZIP includes dgVoodoo2 and SampleAddon.dll. Updating replaces the complete publisher runtime, including dgVoodoo.conf, with backed-up originals; your re5vr.ini and saves remain.

## Controls

| --- | --- |
| [[Insert]] / [[Left Stick Click]] + [[Right Stick Click]] | Open or close the mod menu. |

| [[Left Stick]] | Move. |
| [[Right Stick]] | Turn. |
| [[Left Trigger]] (hold) + [[Right Stick]] | D-pad modifier (default mapping). |
| [[Right A]] / [[Right B]] | Game actions / menu choices. |
| [[Left X]] / [[Left Y]] | Reload / partner command. |
| [[Left Grip]] | Left shoulder input; grip at support-side belt takes ammunition for manual reload. |
| [[Right Grip]] at the shoulder | Draw the knife (right-handed mode). |
| [[Menu]] | Start / pause. |
| [[A]] / [[B]] | Select / back in mod menu. |
| [[LB]] / [[RB]] | Change mod-menu tabs. |
| [[Arrow Keys]] / [[Space]] / [[Esc]] | Navigate / select / close the keyboard menu. |
| [[Ctrl]] + [[Left Mouse Button]] | Enter a slider value directly. |
| [[Left Stick Click]] + [[Right Stick Click]] (T-pose) | Calibrate after enabling 6DOF arms; follow the menu instructions. |

## Updates and Removal

Use the Hub installer for the latest official Windows VR package. A failed copy or incomplete package does not mark the update complete. Setup backs up replaced files; Uninstall now removes only unchanged Hub-owned files and restores originals. Changed user settings, saves, textures, disc images and unrelated files are kept.
