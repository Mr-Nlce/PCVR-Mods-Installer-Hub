# Oblivion (2006) VR

## About the Game

The Elder Scrolls IV: Oblivion is the original 2006 open-world role-playing game set across Cyrodiil and the Daedric realms. OBVR adds native stereo OpenXR, head tracking and VR-native menus to the classic release.

## Requirements and support status

- Use the original **Oblivion 1.2.0.416**, not Oblivion Remastered.
- Steam is tested. GOG and retail builds with the final patch may work but are currently untested by the author.
- This is a **WIP** release. Motion-controlled hands are disabled; use a gamepad or keyboard and mouse.
- The installer obtains OBVR, xOBSE 22.13 or newer, 32-bit DXVK and SteamVR's 32-bit OpenVR runtime. MenuQue v16b must be downloaded manually from Nexus.
- Disable the Steam Overlay. Start SteamVR before using **Start in VR**.
- Oblivion Reloaded variants, Enhanced Camera and ENB can conflict with OBVR or DXVK.

## Installation and removal

**Start in VR** starts SteamVR first and then launches `obse_loader.exe` for Steam, GOG and retail installations. OBVR uses OpenVR, so VDXR is not an alternative runtime for this mod. The route follows the current OBVR release directly and avoids sending the Steam build through the ordinary launcher/overlay path. Keep Steam Overlay disabled for Oblivion. **Uninstall now** removes the Hub-owned OBVR, xOBSE, DXVK and OpenVR files while preserving changed files and restoring prior collisions. MenuQue is left installed because other Oblivion mods may share it.
