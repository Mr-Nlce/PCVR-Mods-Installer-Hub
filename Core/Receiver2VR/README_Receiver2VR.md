# Receiver 2 VR

Receiver 2 has an **official VR mode** built right into the Steam version - no mod required. It's shipped as a Steam **beta branch** called `vr_release_candidate` ("VR Release Candidate"). You switch to it from the game's Steam properties.

## Requirements
- **Receiver 2** on Steam (AppID 1129310), owned + installed
- SteamVR
- Motion controllers

## How to enable VR
1. Click the Hub button - it opens **Receiver 2's properties** in Steam.
2. Go to the **Betas** tab.
3. Open the beta dropdown and scroll to the **bottom** of the list.
4. Select **`vr_release_candidate` - VR Release Candidate**.
5. Let Steam download the branch, start **SteamVR**, then launch Receiver 2 as usual.

> To go back to the normal flat game, repeat the steps and switch the beta back to the default public version.

## Notes
- This is not a third-party mod - it's an official (if old, dated 4 Sept 2020) VR build from Wolfire shipped on a Steam branch.
