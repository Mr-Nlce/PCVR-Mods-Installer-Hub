# I Hate This Place VR

## About the Game

Explore a cursed land in a survival horror game styled like an 1980s comic. Scavenge, craft and build shelter while using stealth and sound to survive creatures that hunt in the dark.

## What you need

- The installed Windows game, an active OpenXR runtime and motion controllers.
- King-EJ tested this mod with Quest 3 and Virtual Desktop's VDXR runtime. First-person and the original raised camera are both supported.

## Install and start

1. Close the game and choose [[Install]] or [[Update]] in the Hub. Check the displayed game folder; Locate Game also accepts the game EXE or its folder.
2. Read the instructions, then press [[Enter]]. The official ZIP includes the publisher's BepInEx IL2CPP loader, .NET runtime, VR plugin and OpenXR bridge. Setup keeps existing settings, saves and unrelated plugins.
3. Start your OpenXR runtime and use [[Start in VR]] in the Hub. The Steam route starts through Steam; a manually selected non-Steam installation uses its own EXE. First launch may take longer while BepInEx prepares the game.
4. For the Steam installation, starting I Hate This Place through Steam is also supported.

If a download fails, download the official mod ZIP and drag it onto the recovery window. The installed version comes from the bundled VR configuration, independently of the rolling GitHub tag.

## Controls

Right-handed defaults. FirstPerson is the default; Normal keeps the original camera. In Normal mode the right stick retains the game's aiming and throw-distance controls.

| Button | Action |
| --- | --- |
| [[Left Stick]] | Walk where you look; navigate menus. |
| [[Right Stick Left]] / [[Right Stick Right]] | Turn in first-person mode. |
| [[Right Stick Up]] / [[Right Stick Down]] | D-pad right / left in first-person mode. |
| [[Right Stick Click]] | Toggle FirstPerson / Normal camera. |
| [[Right Trigger]] | Shoot; aim with the right controller while held. Point and click title/pause menus. |
| [[Left Trigger]] | Throw (game RB); while held, point the right controller to move the throw target. |
| [[Right Grip]] | Aim / ready; show the laser while held. |
| [[Left Grip]] | Game LB. |
| [[Left Stick Click]] | Toggle running until you stop or click again. |
| [[Left Grip]] + [[Left Stick Click]] | Toggle flashlight. |
| [[A]] | Confirm / game A. |
| [[Y]] | Tap for D-pad up; hold for game Y. |
| [[B]] | Sneak / game B. |
| [[X]] | Tap for game X; hold for Back / View. |
| [[X]] + [[Y]] | Pause / Start. |
| [[Left Stick Click]] + [[Right Stick Click]] | Recenter. |
| [[Right Controller]] | Swing a held melee weapon into a target to attack; [[Right Trigger]] still attacks. |

## Settings and help

Settings are in BepInEx/config/ihatethisplace.vr.cfg and update live. MeleeSwingMode uses Collision by default; Swing is optional. If effects differ between the two eyes, use VR settings to disable rendering features one at a time; the choices are saved. ViewMode, world scale and the Normal camera zoom/height can be adjusted.

For problems, include BepInEx/LogOutput.log and the installed mod/game versions in the discussion. Existing configuration is preserved during updates.

## Remove or restore

Use [[Uninstall now]] with the game closed. Unchanged Hub-owned VR files are removed and replaced originals restored. The loader remains when other plugins need it. Saves, changed settings and unrelated files remain. A failed installation restores the previous file set and keeps Retry available.
