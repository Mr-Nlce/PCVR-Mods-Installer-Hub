# Portal 2: Community Edition VR

**Portal 2: Community Edition (P2:CE)** is a free, community-maintained version of Portal 2 on Steam, powered by Strata Source - a modernized fork of the Source engine (CS:GO engine branch) with native DirectX 11, a 64-bit build and broad performance gains over the original game. You must own Portal 2 on Steam to download P2:CE; all the Portal 2 content ships with it.

This is an **external Steam app**: the Hub button opens its Steam store page. There is no Hub installer - you install it from Steam and add one launch option.

## Requirements
- Portal 2 owned on Steam (required to download P2:CE)
- SteamVR running before you launch

## Setup (that's all there is)
1. Install **Portal 2: Community Edition** from Steam (free).
2. In Steam, right-click it -> **Properties** -> **General** -> **Launch Options**.
3. Add the launch option below (click it to copy), then paste it in.
4. Start **SteamVR**, then launch with **Start in VR** in the Hub (or via Steam).

## Launch option

```
-vr
```

## What works, what doesn't
- **Full motion controls** (tested on Quest) and the complete control scheme work once you are in a chamber - this is proper 6DoF VR, not a flat screen in a headset.
- **In-game menus only work partly in VR.** Menu navigation is the weak spot - the same broken-menu trait the Source-engine VR mods (L4D2 / HL2) are known for. You may need to glance at the flat window for some menu steps.

## Heads-up
P2:CE is in an **open beta**: it is publicly playable but not a finished release, so expect occasional crashes, bugs and changes between updates. VR behaviour in particular can shift as the project evolves.
