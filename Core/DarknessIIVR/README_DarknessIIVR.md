# The Darkness II VR

## About the Game

Jackie Estacado returns in a story-driven first-person shooter. Trilex adds OpenXR motion controls, independent dual-wield aiming, gesture reloads and physical control of the Darkness tentacles.

## Install and play

1. Close The Darkness II and open **Install** in the Hub. Select **Only this game** for a dedicated setup.
2. When Trilex opens, select **The Darkness II** and confirm the game folder shown by the Hub. Click **Install selected**. HD textures are optional and take additional preparation time.
3. Close Trilex when it finishes. The Hub verifies the installed files. Connect your headset and choose **Start in VR**. Steam installs start through Steam.
4. To repair or remove the mod, open Trilex for the same folder and use its repair or **Restore / uninstall** action.

## Controls

| Button | Action |
| --- | --- |
| [[Left Stick]] | Move |
| [[Right Stick Left]] / [[Right Stick Right]] | Turn |
| [[Right Stick Up]] / [[Right Stick Down]] | Jump / crouch |
| [[Left Trigger]] / [[Right Trigger]] | Fire the respective weapon |
| [[A]] / [[Cross]] or [[X]] / [[Square]] | Interact or reload |
| [[Left Grip]] | Grab with the left tentacle. Hold, swing, then release to throw |
| [[Right Grip]] | Hold and swing to slash with the right tentacle |
| [[Left Grip]] + pull toward yourself | Extract a heart when aiming at an eligible enemy |
| [[Right Stick Click]] | Hold for the weapon wheel, aim at a weapon, then release |
| [[Left Grip]] near the fore-end | Hold a two-handed weapon with the support hand |
| [[B]] / [[Circle]] | Hold to show objectives |
| [[Y]] / [[Triangle]] | Double-tap to pause |
| [[Left Stick Click]] + [[Right Stick Click]] | Recenter. Hold briefly to switch temporarily to cinema mode |
| [[Right Trigger]] / [[B]] | Select / close in the VR settings panel |

Lower your weapon hand near your upper thigh to gesture-reload. Keep the grip and trigger released during the gesture. The publisher's support thread has the full controls and current gameplay notes.
