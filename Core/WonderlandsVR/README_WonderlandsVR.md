# Tiny Tina's Wonderlands VR

## About the Game

Create a Fatemaker and shoot, loot and cast through Tiny Tina's fantasy campaign. Trilex adds OpenXR stereoscopy, tracked weapon aiming, a support grip, a wrist HUD and motion controls.

## Install and play

1. Install the Steam edition and close the game.
2. Open **Install** in the Hub. Select Tiny Tina's Wonderlands and its Steam folder in Trilex, then click **Install selected**.
3. Close Trilex when finished. Connect the headset and select **Start in VR**. The Hub passes DirectX 11. When launching manually through Steam, set the game's launch option to `-dx11`.
4. Use **Restore / uninstall** in Trilex to restore the files it managed.

The publisher reports a one-eye rendering issue with **DLSS Quality** and with the green weapon reticle. Disable DLSS Quality if gameplay renders in one eye. The public package supports Steam.
