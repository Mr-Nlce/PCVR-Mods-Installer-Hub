# Freespace 2 VR (FreeSpace Open via Knossos)

Brings the 1999 space-combat classic **FreeSpace 2** to modern headsets
through the **FreeSpace Open** source port, managed by **Knossos.NET**.
There is no longer a single separate "VR mod" - VR support is now
**native in every mod/build** you load through Knossos.

This is an **external** setup: the Hub does not install anything for it.
The button on this page opens the Knossos.NET project so you can grab the
latest release and set it up yourself.

## Requirements

- An owned copy of **FreeSpace 2** (Steam app 273620, or GOG). Knossos
  copies the data from your original install and runs **standalone**
  without modifying the original game.
- **Knossos.NET** (latest release).
- A PC VR headset with OpenVR/OpenXR (SteamVR) running.

## Setup with Knossos.NET

1. Download the latest **Knossos.NET** release:
   https://github.com/KnossosNET/Knossos.NET/releases/latest
2. Launch Knossos and let it locate your retail **FreeSpace 2** install
   (it copies the data into its own standalone library).
3. Install the build / mod you want (e.g. the MediaVPs for upgraded
   graphics, or any campaign).

## Playing in VR

- On a game/mod tile in the **Play** view, click **[[Adv]]**, then
  **[[Play in VR]]**.
- VR options live under **Main -> Settings -> [[Configure]]**.

## Controls

- **Gamepad** is the recommended scheme (a joystick / HOTAS or keyboard
  also work for this flight sim).
- All controls are **fully re-bindable** in the in-game options menu.

## Finding mods in Knossos

- The **Freespace** category collects the big total-conversion mods -
  for example the **FreeSpace 1 campaign** rebuilt with improved
  graphics, or a **FreeSpace 2 multiplayer co-op** upgrade.
- The **Explore** tab lists every other available mod.
